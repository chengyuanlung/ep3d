## 怎麼開始

```
build\Debug\ParametricCADViewer.exe --sample m12-sketch
```
→ **Sketch → New Sketch**（Ctrl+Shift+N）

新命令都在工具列與 `Sketch → Constrain and Dimension`：

| 命令 | 鍵 | 需要的選取 |
|---|---|---|
| Parallel | G | 2 條線 |
| Perpendicular | N | 2 條線 |
| Equal | E | 2 條線，或 2 個圓／弧 |
| Concentric | O | 2 個圓／弧 |
| Midpoint | M | 1 個點 + 1 條線 |
| On object | B | 1 個點 + 1 條線／圓／弧 |
| Tangent | T | 1 線 + 1 曲線，或 2 曲線 |

## A — 平行與垂直

| # | 做這個 | 應該看到 | Result | Notes |

| A2 | 看狀態列的 DOF | 比下約束前少 1 | | |
| A3 | 再畫兩條線，一條**反向**畫（從右往左），選它們按 G | 一樣變平行，**不會**把線頭尾翻轉 | | |

## D — Tangent（最需要你判斷的一項）

| # | 做這個 | 應該看到 | Result | Notes |
|---|---|---|---|---|
| D1 | 畫一個圓，再畫一條**穿過**它的線，選兩者按 T | 線移到與圓相切；圖示 `T` | | |
| D2 | 畫兩個**分開**的圓，選它們按 T | 變成外切（圓心距 = r1 + r2） | | |
| D3 | 看面板那一列 | 寫著 `(outer)` | | |
| D4 | 畫一個大圓，在**它裡面**畫一個小圓，選它們按 T | 變成**內切**（小圓貼在大圓內壁） | | |
| D5 | 看面板那一列 | 寫著 `(inner)` | | |
| D6 | **關鍵判斷**：D4 那組內切之後，把大圓的半徑改大或改小，內切關係還在嗎？（分支是存下來的，不會因為幾何變動而改成外切） | | |
| D7 | 選兩條線按 T | 拒絕，訊息說要「一線一曲線，或兩曲線」 | | |
| D8 | 畫一段**弧**，試著讓一條線與它相切 | 可以成立（弧與圓的處理相同） | | |

## 已知缺口（不需在上面回報為失敗）

見 `docs/M13_SPEC.md` §9。摘要：

1. **Normal / Pierce / Curvature 未做** —— 前置（spline、平面外 3D 參考）在 Core 裡不存在。
2. **Symmetric 未做** —— roadmap §6.1 有列，但不在 `todo.md` §2.1 的 11 項內，本輪未處理。
3. **弧的端點不能被約束**（ADR-M12-003），這限制了 Tangent 在「弧接線」上的實用性。
4. 兩圓相切只約束圓心距，**切點位置**由其他約束決定。
5. Point-on-object 針對的是**無限長的線**，不限制在線段之內。
